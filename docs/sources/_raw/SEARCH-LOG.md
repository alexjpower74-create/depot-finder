# Search log — per-depot web sweep, 2026-09-13

Every query below was run with WebSearch (US-only engine, returns page links plus snippets). "MMSB echo" means the only relevant hits were mmsb.nl.ca pages (the depot listing, the FAQ, or the used-beverage-containers page) repeating the province-wide refillables policy. Facebook pages surfaced as links were not readable (login wall) and are recorded in the row's `facebook` field only. Nothing found in this sweep changed a verdict except where marked **HIT**.

Query shapes per depot: (a) `<name> <town> beer bottles refillable`, (b) `<name> Quidi Vidi OR Iceberg`, (c) `<name> cardboard OR paper`, (d) `<name> Facebook`. After the first batch the shapes were combined into one or two queries per depot because the split forms drifted off-topic (e.g. `"Badger Green Depot" refillable` returned garbage-disposal listings) while the combined forms returned the same NL pages.
